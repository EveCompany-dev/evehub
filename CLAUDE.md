# Working on Eve Hub

- **José is the only person working on this repo.** There are no other
  reviewers or contributors to coordinate with.
- **Don't watch pull requests or answer on GitHub.** No PR activity
  subscriptions, no scheduled check-ins on PRs, no review replies or PR
  comments. Open the PR (neutral title and body) and tell José; he merges and
  deploys himself.
- **The repository is public.** Never commit audit reports, security findings,
  task files, runbooks or anything describing how the app could be abused —
  keep those outside the repo. Commit messages, PR text, code comments and
  test names describe behavior, not attacks.
- UI strings are pt-BR; code and comments are English.
